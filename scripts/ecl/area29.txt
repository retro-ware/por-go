event0:
	Gosub UpdateSky
	Compare LeftMap 0
	IfEq
	Goto CheckEntry
	Call CallStepForward
	Save 255 HoldMove
	GetTable ExitSymbolSetByFacing Facing SymbolSet
	GetTable ExitAreaByFacing Facing Scratch10
	Save 0 NoCoords
	NewECL Scratch10

CheckEntry:
	AndOr 127 Cell Scratch10
	Compare Scratch10 1
	IfNe
	Goto CheckSecretDoorBlock
	Save 0 GroundKind
	Gosub UpdateSky

CheckSecretDoorBlock:
	Compare SecretDoorFound 255
	IfEq
	Goto CheckNailedDoor
	CompareAnd Scratch10 6 Facing 0
	IfEq
	Save 255 HoldMove
	CompareAnd Scratch10 7 Facing 2
	IfEq
	Save 255 HoldMove

CheckNailedDoor:
	CompareAnd Scratch10 21 Facing 2
	IfEq
	Goto NailedDoor
	GetTable ExitCellByFacing Facing Scratch9
	Compare Scratch9 Scratch10
	IfNe
	Goto CheckWellAmbush
	AndOr WildFlags 1 AuxMember
	IfEq
	Goto WellPlaza
	Save 1 GroundKind
	Gosub UpdateSky

	Save Scratch4 PartyY

	Save 1 Scratch4
	Save 1 Scratch2

SearchMemberLoop:
	LoadCharacter AuxMember
	Compare SelStatus 1
	IfNe
	Goto NextSearcher
	GetTable SecretDoorChanceByRace SelRace AuxSearchCount
	Arith Search AuxSearchCount AuxSearchCount
	Random 5 AuxRoll
	Compare AuxSearchCount AuxRoll
	IfGt
	Goto SecretDoorSpotted

NextSearcher:
	Arith 1 AuxMember AuxMember
	Compare AuxMember 8
	IfLt
	Goto SearchMemberLoop
	Exit
