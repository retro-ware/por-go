LoadEncounterData:
	GetTable EncDistTable AuxEncIndex MonsterDist
	GetTable EncMonsterTable AuxEncIndex AuxSightText
	GetTable EncPictureTable AuxEncIndex AuxEncMonster
	GetTable EncTable4 AuxEncIndex AuxEncDist
	GetTable EncMoraleTable AuxEncIndex AuxEncMorale
	GetTable EncTable6 AuxEncIndex AuxEncChoice
	GetTable EncTable7 AuxEncIndex AuxEncChoice2
	GetTable EncStrengthAdjTable AuxEncIndex AuxEncTblA
	GetTable EncGroupStepTable AuxEncIndex AuxEncTblB
	GetTable EncGroupIncTable AuxEncIndex AuxEncTblC
	GetTable EncTable11 AuxEncIndex AuxEncSurpriseA
	GetTable EncTable12 AuxEncIndex AuxEncSurpriseB
	GetTable EncTable13 AuxEncIndex AuxEncBonus
	Save 0 Scratch2
	Save 0 EncounterCount2
	if 1 == EncounterIsOrcs: Goto OrcPatrol
	PartyStrength Scratch1
	Div Scratch1 AuxEncTblA Scratch1
	if Scratch1 < 4: Save 4 Scratch1
	Random 9 Scratch4
	OnGoto Scratch4 5 AddThree AddTwo AddTwo AddTwo CountGroups

AddThree:
	Div Scratch1 3 Scratch1
	Goto CountGroups

AddTwo:
	Div Scratch1 2 Scratch1
	Goto CountGroups

CountGroups:
	Save Scratch1 Scratch3

CountGroupsLoop:
	if Scratch3 < AuxEncTblB: Goto ClampGroupSize
	Add AuxEncTblC Scratch2 Scratch2
	Sub AuxEncTblB Scratch3 Scratch3
	Goto CountGroupsLoop

ClampGroupSize:
	if Scratch1 >= AuxEncTblB: Gosub SetSecondGroup
	if Scratch1 > 56: Sub Scratch2 56 Scratch1
	Save Scratch1 EncounterCount1
	Return

SetSecondGroup:
	Save Scratch2 EncounterCount2
	Return
