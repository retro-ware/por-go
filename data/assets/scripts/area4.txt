RollSurprise:
	PartySurprise Scratch8 Scratch9
	AndOr CastleFlags 1 Scratch10
	IfNe
	Arith 1 Scratch9 Scratch9
	Surprise Scratch8 Scratch9 0 0
	Compare AlarmEndHour 0
	IfNe
	AndOr Surprise 1 Surprise
	Compare Surprise 3
	IfEq
	Save 0 Surprise
	Compare Surprise 1
	Return

CheckAlarm:
	Compare AlarmEndHour 1
	IfLt
	Return
	Save Hours AuxRoll
	CompareAnd Hours 0 AlarmHour 23
	IfEq
	Save 24 AuxRoll
	Compare AuxRoll AlarmEndHour
	IfLt
	Goto AlarmStillOn
	Compare TenMinutes AlarmMinute
	IfLt
	Goto AlarmStillOn
	Save 0 AlarmEndHour
	Compare 0 1
	Return

AlarmStillOn:
	Compare Search 1
	IfEq
	Goto AlarmSounding
	Random 9 AuxRoll
	Compare AuxRoll 0
	IfNe
	Goto AlarmOnReturn

	Print "AN ALARM IS SOUNDING."
	Delay

AlarmOnReturn:
	Compare 1 0
	Return
