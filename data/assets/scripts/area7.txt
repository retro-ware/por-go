	Return

StairsScanLoop:
	GetTable Table99D8 Scratch1 Scratch3
	GetTable Table99E0 Scratch1 Scratch4
	if Scratch2 == Scratch3 && Scratch4 == Facing: Goto StairsDispatch

HoldAtSecretDoor:

	Exit

SecretDoorCheck:
	And SearchTowerFlags 8 Scratch10
	if 0 != Scratch10: Goto SecretDoorFound
	Save 0 Scratch9

SecretDoorRoll:
	LoadCharacter Scratch10
	if SelStatus == 0: Goto SecretDoorNextMember
	Save 1 Scratch9
	if Search == 0: Sub 1 Scratch9 Scratch9
	if SelRace == 2: Add 1 Scratch9 Scratch9
	if SelRace == 4: Add 1 Scratch9 Scratch9
	Random 5 Scratch8
	if Scratch8 <= Scratch9: Goto SecretDoorFound

SecretDoorNextMember:
	Add Scratch10 1 Scratch10
	if Scratch10 < 8: Goto SecretDoorRoll
	Exit

SecretDoorFound:
	Or SearchTowerFlags 8 SearchTowerFlags
	PrintClear "A SECRET DOOR IS FOUND "
	OnGoto Facing 4 DirFront DirLeft DirBehind DirRight
	Gosub PressToContinue
	Exit
