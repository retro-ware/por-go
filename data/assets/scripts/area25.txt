PickEncounter:
	Random 20 Scratch1
	if Scratch1 == 20 && ForceEncounter25 == 0: Return
	Random 19 Scratch1
	OnGoto Scratch1 20 PickBoars PickBoars PickBoars PickMantis PickTigers PickTigers PickTigers PickThriKreens PickThriKreens PickAnkheg PickCentaurs PickCentaurs PickSoldiers PickSoldiers PickThieves BuccaneerBaseSite PickQuicklings PickQuicklings PickSnakes PickSnakes

	GetTable EncData2 EncounterType25 AuxMember
	GetTable EncData3 EncounterType25 AuxRoll
	GetTable EncMonster EncounterType25 AuxMonster
	GetTable EncData5 EncounterType25 AuxEncResult
	GetTable EncMorale EncounterType25 AuxEncResult2
	GetTable EncData7 EncounterType25 AuxEncTemp
	GetTable EncMonster2 EncounterType25 AuxPartyStrength
	GetTable EncStrength EncounterType25 AuxCounter
	PartyStrength Scratch1
	Div Scratch1 AuxCounter Scratch1
	Random 5 Scratch2
	OnGoto Scratch2 5 GroupSizeLarge GroupSizeMedium GroupSizeMedium GroupSizeMedium SplitGroups

GroupSizeLarge:
	Div Scratch1 3 Scratch1
	if Scratch1 <= 0: Save 1 Scratch1
	Goto SplitGroups

GroupSizeMedium:
	Div Scratch1 2 Scratch1
	if Scratch1 <= 0: Save 1 Scratch1

SplitGroups:
	Save 0 EncounterExtraCount25
	Save Scratch1 Scratch3
	GetTable EncGroupSize EncounterType25 AuxMenuChoice
	if AuxMenuChoice == 0: Goto CapGroupSize

SplitGroupsLoop:
	if Scratch3 < AuxMenuChoice: Goto CapGroupSize
	Add 1 EncounterExtraCount25 EncounterExtraCount25
	Sub AuxMenuChoice Scratch3 Scratch3
	Goto SplitGroupsLoop

CapGroupSize:
	if Scratch1 >= 56: Sub Scratch2 56 Scratch1
	Save Scratch1 EncounterCount25
	Return
